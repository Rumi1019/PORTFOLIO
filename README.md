# Rumi Portfolio

A static website. No build step needed.

## Files (all in ONE folder, next to each other)
index.html, styles.css, art.js, data.js, components.js, sections.js, lab.js, main.js

(art.js is new: it holds the two project pictures and the language logos.)

## Put it on GitHub Pages
1. Open your repo, click Add file, then Upload files.
2. Select ALL files above and drop them in. Do not put them in a folder.
3. Click Commit changes.
4. Open Settings, then Pages. Pick branch main and folder root. Save.
5. Wait one minute, then open your site link.

## Best hero photo (transparent PNG)
1. Go to remove.bg (or Adobe Express "remove background") and upload your photo.
2. Download the PNG and rename it to hero.png.
3. Upload hero.png into the same folder as index.html. Done. The site uses it automatically.
Without hero.png the site still shows your photo with soft blended edges.

## Easy edits
- Ticker words: TICKER in data.js
- Logos in the river: LOGOS in art.js
- Project pictures: ART in art.js, or put real screenshot links in SITES in data.js
